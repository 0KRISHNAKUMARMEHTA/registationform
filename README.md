📖 Introduction

The KRIBADCHA Registration Form is designed as a practice project for frontend web development. It demonstrates how to create a structured registration form with client-side validation, live feedback, and animations.

This project can be used as a template for student registration systems, surveys, or event signup forms.


---

✨ Features

📊 Dynamic Progress Bar – Updates as users fill out fields.

🔑 Validation Messages – Inline feedback for incorrect or missing input.

📝 Character Counter – Tracks text input for the “About You” field (max 500 chars).

📂 File Upload Support – Accepts .txt, .pdf, .jpg, .png, .docx.

📅 Date Picker – User-friendly input for selecting a date.

📱 Responsive Layout – Optimized for different screen sizes.

🎨 Modern Styling – Smooth transitions and hover effects.

✅ Submission Simulation – Displays a success message on form

🚀 Usage

1. Open the form in your browser.


2. Fill out required fields (Name, Email, Password, Phone Number, Age, etc.).


3. Upload a file if needed.


4. Submit the form – a success message will appear.


5. Reset to clear all inputs.

🔧 Configuration

Edit style in the <style> section to adjust colors, fonts, and layout.

Modify JavaScript in the <script> section to add validation rules or submission logic.

Replace the form.action attribute with a backend endpoint if connecting to a server.



---

🛠️ Troubleshooting

Progress bar not moving? Ensure JavaScript is enabled in your browser.

Validation messages not showing? Check that the required attributes are present.

File not uploading? Verify accepted file formats (.txt, .pdf, .jpg, .png, .docx).

Form not submitting to server? Add a proper backend action URL in the <form> tag.
